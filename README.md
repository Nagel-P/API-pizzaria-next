📚 Pizzaria Digital

🧾 Descrição  
Esta aplicação tem como objetivo oferecer um sistema completo para gerenciamento de uma pizzaria, tanto no atendimento ao cliente quanto na administração interna. Através de uma API RESTful e um front-end dinâmico, o sistema permite a visualização de um cardápio online, a realização de pedidos personalizados, e o acompanhamento do status do pedido em tempo real.  

Além disso, o sistema oferece funcionalidades administrativas como controle de estoque, cadastro de produtos e visualização de relatórios de vendas, tornando a gestão da pizzaria mais eficiente e moderna.
